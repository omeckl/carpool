# Telekocsi — Carpool web app

Created by Orsolya Meckl and Jozsef Kovesi

A ride-sharing web app that connects drivers and passengers for everyday trips:
list a ride, book a seat, and exchange contact details automatically.

**Showcase:** https://omeckl.github.io/carpool/

## Tech stack

React 19 · TypeScript · Vite · Tailwind CSS v4 · Supabase

## Running locally

1. Create a `.env` file with `VITE_SUPABASE_URL` and `VITE_SUPABASE_PUBLISHABLE_KEY`.
2. `npm install`
3. `npm run dev`
